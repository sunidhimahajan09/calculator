# Simple C++ CLI Calculator

A lightweight, interactive command-line calculator built in C++ to perform basic arithmetic operations with input validation and safe zero-division checks.

## 🚀 Features
- **Operations:** Addition, Subtraction, Multiplication, Division.
- **Interactive Menu Loop:** Perform multiple calculations seamlessly without restarting the program.
- **Error Handling:** Safe checks for zero-division errors and invalid menu selections.
